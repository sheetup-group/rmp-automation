# Emulator tools

Skrip bantu untuk emulator Android lokal (macOS, Apple Silicon).

- `setup.sh` : pasang SDK command-line tools, emulator, system image, buat AVD
- `env.sh`   : set ANDROID_SDK_ROOT, JAVA_HOME, PATH
- `float.sh` : buka app sebagai jendela mengambang sementara (`off` untuk menutup)
- `move.sh`  : geser / ubah ukuran jendela mengambang
- `apps.sh`  : daftar app yang bisa dipilih
- `keys.sh`  : pengganti tombol toolbar emulator (home, back, recents, ...)

Tidak ada kredensial, data customer, atau screenshot di repo ini.
